# ♛ Chess Vision Pro - Mobile App

**Professional-Grade Chess Puzzle & Analysis Suite for Android**

Developed by **Akbar Hossain** | Agartala Chess Academy

## 🎯 Features

### Core Features
- 📚 **Lichess Puzzle Database** - Access thousands of tactical puzzles offline
- 🎨 **Beautiful Material Design 3 UI** - Modern, responsive, and intuitive interface
- 🧩 **Advanced Puzzle Search** - Filter by rating, themes, and openings
- 🏆 **Engine Analysis** - Deep Stockfish integration with multi-PV evaluation
- 📊 **Statistics & Progress Tracking** - Monitor your improvement
- 🌐 **Multi-Language Support** - English, Spanish, Portuguese, French, Chinese, Dutch

### Chess Features
- ♟️ **Interactive Chess Board** - Drag-and-drop moves with visual feedback
- ⚙️ **Customizable Themes** - Multiple board and piece themes
- 🔊 **Audio Feedback** - Move sounds and notifications
- 📈 **Evaluation Bar** - Visual engine evaluation with best moves
- 💾 **Game Library** - Save and analyze your games
- 🎓 **Learning Mode** - Step-by-step puzzle solving with hints

## 📱 Screenshots

- **Home Screen** - Quick access to all features
- **Puzzle Trainer** - Interactive puzzle solving with engine analysis
- **Analysis Board** - Deep analysis with multi-PV engine lines
- **Search Interface** - Advanced puzzle filtering
- **Settings Panel** - Full customization options

## 🚀 Getting Started

### Requirements
- Android 7.0+ (API 24)
- 100 MB storage space
- 4 GB RAM (recommended)

### Installation
```bash
# Clone the repository
git clone https://github.com/akbartube51-a11y/akbar_app.git

# Open in Android Studio
cd akbar_app

# Build and run
./gradlew installDebug
```

## 🏗️ Architecture

- **MVVM** - Model-View-ViewModel pattern
- **Jetpack Compose** - Modern declarative UI framework
- **Room Database** - Local puzzle storage
- **Dagger Hilt** - Dependency injection
- **Coroutines** - Async operations
- **Retrofit** - API communication

## 🎮 How to Use

1. **Start Puzzle** - Begin solving puzzles from the home screen
2. **Search** - Filter puzzles by rating, theme, and opening
3. **Analyze** - Use the analysis board for deep engine evaluation
